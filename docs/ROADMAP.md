# 模块路线图

更新时间：2026-11-22。以下为方向与待办，不承诺发布日期。

## 已有实现基础

主项目已有网页播放、搜索与版本确认、LX 兼容脚本接入、下载校验、标签与歌词补齐、本地扫描、文件整理、持久任务及限流冷却。它们仍属于同一个服务，尚未形成独立发布的模块包。

## 开放准备

- [x] 创建 GitHub 私有展示仓库，审阅真实 README 效果。
- [x] 聚焦在线听歌、搜索、音源、下载、刮削、曲库整理与限流。
- [ ] 选定许可证并核对代码权属和依赖。
- [ ] 审核拟上传源码、历史、配置和文档中的私人信息。
- [ ] 准备通用 Compose、隔离开发环境和安装指南。
- [ ] 补充真实脱敏截图、公开验证结果。
- [ ] 确定 Gitea 与 GitHub 的分支同步、贡献回流方案。
- [ ] 用户确认后再开放仓库。

## 模块化方向

| 模块 | 需要明确的边界 |
| --- | --- |
| 音源适配 | 能力声明、查询与解析、超时、错误类型、来源可用性 |
| 下载执行 | 流式传输、完整性校验、幂等、暂存与发布恢复 |
| 元数据刮削 | 标签、歌词、封面、匹配置信度、缺项与人工锁定 |
| 曲库整理 | 文件命名、目录、去重、冲突、索引与导出 |
| 限流调度 | 全局与来源级控制、冷却、重试、任务状态与恢复 |
| 网页播放 | 搜索试听、库内播放、队列、歌词与任务反馈 |

先明确接口并补测试，再决定哪些模块值得独立发布；不预先拆出空包。

## 产品范围

不再推进 Android 客户端；现有代码与历史留在主仓库，本轮未删除。App Store 保留为后续发行意向，不作为此次开源准备的前置条件。
